一款专为 **番茄免费小说** 打造的 LSPosed 界面定制模块。

支持精简应用界面、隐藏不需要的功能入口、调整阅读体验、本地vip状态、免广告，以及查看书籍内部编号。所有功能均提供独立开关，可根据个人需求自由配置。

## 📱 兼容性要求

| 项目 | 要求 |
|---|---|
| 目标应用 | 番茄免费小说 |
| 应用包名 | `com.dragon.read` |
| 适配版本 | **7.3.9.32（73932）** |
| Android 版本 | Android 9 及以上 |
| 框架要求 | 支持 libxposed API 102 的 LSPosed 框架 |
| 模块包名 | `io.github.mianxyz.fanqiecustomizer` |

**注意：** 本模块仅针对指定版本进行适配，其他版本的番茄免费小说不会加载本版适配规则。

## 🧩 功能列表

### 🏠 首页与书城

- 分别隐藏底部导航入口。
- 自定义默认启动的底部导航。
- 保留内部主页路由适配。
- 分别隐藏书城频道。
- 自动保留至少一个实际可用的频道或导航入口。
- 隐藏福利浮动图标。
- 隐藏发帖快捷按钮。
- 隐藏自动短剧续播浮窗。

### 📚 书架

- 自动展开全部书籍。
- 隐藏金币相关控件。

### 👤 我的页面

支持分别隐藏：

- 收益记录。
- 常玩游戏。
- 原有九项功能入口。

平板界面还可分别隐藏：

- 视频创作。
- 兴趣偏好。
- 我的笔记。
- 看过的人。
- 番茄指南。
- 我的钱包。
- 活动中心。
- 我的公益。

### 📖 阅读界面

- 隐藏已适配的阅读广告组件。
- 隐藏直播推广内容。
- 隐藏广告横幅及其占位区域。
- 隐藏章节末尾免广告入口。
- 隐藏快捷听书入口。
- 隐藏小游戏入口。

### 🔎 书籍编号工具

- 显示书籍内部编号。
- 一键复制书籍编号。
- 通过编号搜索并直达书籍。
- 提供原生编号工具。

### ⚙️ 其他

- 本地 VIP 状态
- 显示接口返回的原始阅读计数字段。
- 诊断已发现的配置名称。
- 关闭自动更新弹窗。
- 隐藏或恢复桌面模块图标。
- 输出功能命中日志。

**功能限制说明：**

- 广告隐藏仅覆盖已适配的组件，不保证屏蔽全部动态广告模板。
- 原始阅读计数字段不代表经过验证的实时真实在读人数。
- 下架书籍能否访问仍取决于服务器状态及已有内容。
- 本地 VIP 判断不会开通服务端会员权益。
- 免广告送爱发电礼物功能暂未加入。

## 🔒 隐私说明

模块不包含主动上传数据或统计用户行为的功能。

模块自身的诊断输出范围仅限已限定的技术类型、配置名称和布局数据，不主动输出：

- 书籍名称或书籍编号。
- 用户账号信息。
- 完整异常正文。
- Intent 内容。
