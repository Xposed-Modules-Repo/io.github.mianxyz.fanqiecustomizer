# 番茄界面定制 5.0.5

用于番茄免费小说的 LSPosed 模块，提供界面精简、阅读界面调整和书籍编号工具，各功能独立开关。

仅适配番茄免费小说 `com.dragon.read`，**7.3.9.32 / 73932**；需要 Android 9 或更新版本，以及支持现代 libxposed API 102 的框架。其他番茄版本不会加载本版适配规则。

本版包名 `io.github.mianxyz.fanqiecustomizer`，versionCode 为 22，沿用原签名。

## 本版变化

5.0.5 将模块包名迁移为与公开 GitHub 账号对应的命名空间，为仓库收录准备发布身份。功能以 5.0.2 为基础，保留 5.0.4 的底部导航隐藏修复，未继承已弃用的 5.0.3 开屏相关功能、开关或代码。

开启底部导航隐藏后，原逻辑要等页面布局后的扫描才隐藏，首次绘制可能看到全部入口。本版在原生导航栏创建、添加按钮和切换展示时立即处理，并在该导航栏绘制前复核，处理首次进入和后续刷新时的闪现。

沿用现有隐藏开关，不增加配置项。不删除或重排原始导航列表，保留页面、点击索引及默认启动底栏的关联；只调整对应按钮可见性。未知入口保留，服务器实际入口全部命中隐藏时仍保留首个实际入口。延迟扫描兜底与展示前逻辑使用相同规则。

启用任一底栏隐藏选项时，首页独立的五图标启动动画改走原生静态图标分支，防止动画再次绘出已隐藏的入口；不修改全局图标或动画配置。

保留 5.0.2 的发帖快捷入口提前隐藏、桌面图标隐藏与恢复，以及阅读页码功能移除。

## 安装与旧版迁移

**5.0.5 包名与旧版不同，不能覆盖旧版安装，也不会自动继承旧配置。**

1. 先记录旧模块中需要保留的选项，在 LSPosed 中禁用旧版“番茄界面定制”。旧版可以保留安装，但不要同时启用两个版本。
2. 安装 5.0.5，在 LSPosed 中启用新模块，作用域选择番茄免费小说。可在应用详情中核对新包名 `io.github.mianxyz.fanqiecustomizer`。
3. 打开新模块，重新设置需要的选项，等待“配置已同步”。
4. 强行停止番茄，再重新打开。修改番茄相关选项后，也需要执行这一步。

“更多”中的桌面图标开关立即生效。隐藏图标后，可从 LSPosed 的模块设置入口重新打开。将来同包名、同签名的版本可正常覆盖更新。

番茄内打开模块设置的旧功能继续保持移除；保留的“书籍编号工具”仅提供编号直达。

## 保留的功能

- 底部导航分别隐藏、默认启动底部导航选择，至少保留一个实际入口；内部主页路由适配继续保留。
- 书城各频道分别隐藏，保留实际可用频道；福利浮图、发帖快捷按钮、自动短剧续播浮窗隐藏。
- 书架自动展开全部、金币控件隐藏。
- 我的收益记录、常玩游戏和原有九项功能入口分别隐藏。
- 平板可分别隐藏视频创作、兴趣偏好、我的笔记、看过的人、番茄指南、我的钱包、活动中心、我的公益。
- 阅读广告组件、直播推广、横幅及占位、章末免广告入口、快捷听书与小游戏隐藏。
- 书籍内部编号显示和复制、编号搜索直达、原生编号工具、尝试跳过本地下架检查。
- 接口原始阅读计数字段显示、已发现配置名称诊断、关闭自动更新弹窗、实验性本地 VIP 判断。

广告隐藏覆盖已适配组件，不保证覆盖所有动态广告模板。接口原始计数不能证明实时真实在读人数。下架书籍仍取决于服务器与已有内容，本地 VIP 判断不会开通服务端会员。免广告送爱发电礼物尚未加入。

## 日志与隐私

桌面模块 → 更多 → 输出命中日志，等待配置同步后强行停止并重开番茄，复现问题；在 LSPosed → 日志 → 模块日志中搜索 `FanqieCustomizer`。日志保存在自行选择的位置，分享前检查并遮盖敏感内容。

模块没有主动上传或统计功能。自有诊断只输出已限定的技术类型、配置名称和布局数据，不主动输出书名、书籍编号、账号、完整异常正文或 Intent 内容。公开的 `mianxyz` 命名空间是本次授权使用的发布标识。完整 LSPosed 日志可能包含系统、框架及其他应用的数据。详细检查范围见 [PRIVACY.md](PRIVACY.md)。
